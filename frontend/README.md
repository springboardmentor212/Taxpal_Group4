# TaxPal – Landing Page (Frontend)

TaxPal is a modern tax management web application.  
This repository contains the **Landing Page UI** of the TaxPal project, built using **React + Vite** with **Tailwind CSS**.

> ⚠️ Note:  
> The **core dashboard and backend logic** were developed by other team members.  
> **My contribution** is focused on designing and implementing the **Landing Page & UI components**.

---

## 🔥 What I Worked On

I was responsible for building the **TaxPal Landing Page**, including:

- Hero Section (Introduction & CTA)
- Features Section
- Dashboard Preview (Carousel)
- Charts & Analytics UI
- Stats Section with animated counters
- PDF / CSV Reports UI
- Final Call-To-Action
- Footer
- Responsive & clean UI design

---

## 🛠️ Tech Stack Used

- **React.js**
- **Vite**
- **Tailwind CSS**
- **Recharts** (for charts UI)
- **JavaScript (ES6+)**
